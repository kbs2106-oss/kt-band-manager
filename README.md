# 칠금점 가망고객 밴드

충주 KT대리점 칠금점 직원용 **가망고객 밴드 웹앱(PWA)** 입니다.
네이버 밴드처럼 공지 · 상담놓침 · 730/550/3년 명단 · 사전예약을 글·사진·댓글·대댓글로 주고받습니다.
1단계 댓글은 **고객 한 명(연락처/생년월일 + 부재·예약·완료·개통완료 4칸)**, 대댓글은 **직원 진행 보고**입니다.

- 주소: https://kbs2106-oss.github.io/kt-band-manager/
- 설치: 폰 브라우저에서 주소를 연 뒤 **홈 화면에 추가** (안드로이드 크롬 · 아이폰 사파리)
- 현재 버전: **v8.20**
- 전 직원 실시간 공유: 개통장부 공용 Apps Script(`apps-script/Code.gs`)의 숨김 탭 `_밴드공유` 와 `band_get`/`band_push` 로 주고받습니다
- 전용 안드로이드 앱: **칠금점 가망고객** APK (**v1.0.4** · https://kbs2106-oss.github.io/kt-band-manager/apk/kt-band.apk) — 화면 캡처 차단(관리자 모드에서만 허용) · 등록 알림 · **v1.0.3부터 `바로 촬영`이 앱 안에서 카메라를 직접 열고, v1.0.4부터 예약 시각이 되면 앱이 꺼져 있어도 폰 상단 알림이 울립니다**(재부팅·앱 업데이트 뒤에도 다시 걸림)

### v8.20에서 달라진 점

- **앱을 껐다 다시 켜면 홈 피드는 늘 접힌 기본 상태** — 댓글을 펼쳐 보다가 앱을 나갔다(홈·최근앱·잠금) 다시 열면, 펼쳐 둔 글 댓글·날짜 카드가 **모두 접힌 채 첫 댓글 미리보기만** 보이는 기본 화면으로 시작합니다. 앱 안에서 펼쳤다 접는 동작은 그대로이고, 잠깐 다녀온 경우(1.5초 미만)·사진 고르는 중·댓글 창이 열려 있을 때·입력 중일 때는 건드리지 않습니다. 보던 글은 화면에서 사라지지 않고 그 자리에 남습니다.
- **`모두 접기` 를 눌러도 보던 글이 아래로 튀지 않습니다** — 댓글 20개가 넘는 글을 펼쳐 읽다가 `모두 접기`(또는 글별 `💬 댓글 접기`)를 누르면, 글 높이가 줄어들면서 다른 글로 내려가던 문제를 고쳤습니다. 접은 뒤 **그 글 카드의 위가 상단 고정 바 바로 아래(14px)** 에 오도록 자리를 맞춥니다(390·360·320 모두).
- **`사전예약 명단` → `사전예약 확정건`** — 사전예약 글 안 박스 제목이 **사전예약 확정건** 으로 바뀌었고, 안내 문구는 `아직 확정된 예약이 없어요. 아래 ＋ 확정건 추가로 등록해 보세요.`, 버튼은 `＋ 확정건 추가`(추가 창 제목 `사전예약 확정건 추가`), 글 아래 요약 칩은 `확정건 N` 입니다.

### v8.19에서 달라진 점

- **미리보기 댓글을 누르면 댓글 창이 열립니다** — 홈 피드 카드에 보이는 첫 댓글(글자·사진) 미리보기를 누르면 그 글의 **댓글 창(글 상세 시트)** 이 열리고, 미리보기로 보던 그 댓글까지 바로 내려가 잠깐 노랗게 강조됩니다. 미리보기 안의 **작은 사진**을 눌러도 (크게 보기 대신) 댓글 창이 열리고, 댓글 창 안에서 사진을 누르면 예전처럼 크게 볼 수 있습니다. 미리보기 오른쪽에 `댓글 N ›` 표시가 붙습니다.
- **예약 목록의 `상담 댓글` 을 누르면 그 댓글까지** — 730·550·3년 탭의 `⏰ 예약 고객`(그리고 부재중 킵) 목록에서 `상담 댓글`로 표시된 항목을 누르면 그 상담 글의 댓글 창이 열리고, **해당 댓글 위치까지 스크롤 + 노란 강조**로 바로 눈에 띕니다.
- **예약 목록 기본 정렬 = 가까운 순** — 오늘·가장 임박한 예약이 맨 위, 다가오는 예약은 날짜 오름차순, **지난 예약은 맨 아래**(`지난 예약` 줄로 구분)에 최근 것부터 모입니다.
- **예약 필터 칩 + 정렬 전환** — `⏰ 예약 고객` 머리말 바로 아래에 **`전체` · `오늘` · `7일 이내` · `지난 예약`** 칩과 오른쪽 **`가까운 순 ⇅` / `최근 등록순 ⇅`** 전환 버튼이 생겼습니다(390·360·320 폰에서 넘침 없음).
- **수기로 올린 예약은 장부로 개통완료 되지 않습니다** — `＋ → ⏰ 예약 추가`로 올린 예약 고객(구분 `예약`)은 전화번호가 개통장부의 개통 건과 같아도 **자동 `개통완료` 반영 대상에서 빠지고 `예약` 상태 그대로** 남습니다. 730·550·3년 명단 고객만 장부와 대조해 자동 개통완료 처리됩니다.

### v8.18에서 달라진 점

- **관리자 모드 전용 `🗑️ 삭제`** — 관리자 PIN(0525)으로 관리자 모드를 켜면 홈 피드의 **글 카드와 글 상세 시트** 아래에 빨간 `🗑️ 삭제` 버튼이 생기고, `⋯` → **글 관리** 시트에도 `🗑️ 글 삭제` 가 추가됩니다. **일반 직원 화면에는 보이지 않습니다.**
- **[취소][삭제] 확인** — 누르면 「글 제목」 글을 지울까요? 확인 창이 뜨고, `삭제` 를 누르면 이 폰의 피드에서 바로 사라진 뒤 `band_push`(`f.deleted=true`)로 **전 직원 폰에서도 함께 사라집니다**(직원 폰에는 `○○ 삭제 반영` 안내가 잠깐 뜹니다).
- **시드 공지도 지워지면 다시 안 살아남** — 시드(`real_band_seed_v8.json`)에 들어 있는 공지도 삭제할 수 있고, 삭제 표시(`delPost`)가 저장본에 남아 앱을 다시 켜거나 새 시드가 배포돼도 되살아나지 않습니다. 이미 지운 글에 늦게 도착한 수정(옛 버전 기기)도 무시합니다.
- **옛 버전 기기에서 넘어올 때** — v8.17 기기가 서버의 삭제 표시를 먼저 받아 글에 `deleted` 만 적어 둔 경우도, v8.18 이 켜질 때 삭제로 옮겨 피드에서 빠집니다.
- **확인 창 줄바꿈** — 확인 창 안내 문구의 줄바꿈이 그대로 보입니다.

### v8.17에서 달라진 점

- **폰 알림** — 예약을 저장하면 `KTBandBridge.notify('⏰ 예약 알람', '고객 · 11/27(오후 2:00)')`로 한 번 알리고,
  앱을 열 때 오늘·지난 예약 건을 **하루 한 번**(같은 예약은 다시 울리지 않음) 알립니다. 알람 예약 훅(`KTBandBridge.scheduleAlarm`)이 있는 앱이면 함께 걸어 둡니다.

- **전체 시인성** — 배경 `#F4F6F9` ↔ 흰 카드 `#FFFFFF` + 선명한 보더(`#E3E8EF`)와 옅은 그림자.
  고객 이름 17px·굵게, 전화번호 15.5px·굵게, `남은 N`·`미통화 N`·상단 숫자는 더 크고 진하게. 흐리던 보조 글자는 `#475569` 이상으로 올려 읽기 편하게 정리했습니다.
- **상태 이름 `완료` → `개통완료`** — 명단 4칸, 상단 숫자, 필터 칩, 댓글 4칸, 부재중 킵, 고객 시트, 사전예약까지 모두 `개통완료`로 통일했습니다.
  글 자체를 마감하는 버튼은 `처리완료`입니다. (저장된 상태 값은 그대로라 기존 데이터가 깨지지 않습니다.)

### v5에서 달라진 점

- **댓글이 곧 고객 카드** — 글(예: `11월 상담건`, `상담놓침`)의 **1단계 댓글마다** `미통화 · 부재 · 예약 · 완료` 4칸 버튼이 붙습니다.
  댓글에 `01037795774/970114`처럼 고객 정보를 남기고 버튼 한 번으로 상태를 바꾸면, `완료`는 그 댓글 블록이 차분한 회색(`#F1F3F5`)으로 마감됩니다.
  **대댓글(답글)에는 상태 버튼이 없습니다** — 직원 진행 내용·사진만 남기고 `답글 N개 보기 ▾`로 접었다 펴며, 댓글 입력창도 답글 모드로 바꾸면 상태 칩이 사라집니다.
- **사전예약 공지 작성** — `＋ 글쓰기`의 `사전예약 공지`로 올리면 **상단 고정 공지 + 사전예약 탭**에 바로 뜨고(고정은 기본 체크, 해제 가능),
  글 안에서 `＋ 예약자 추가`와 `개통 체크(N/M 개통)`를 바로 관리합니다. 등록 직후 그 글이 열려 예약자를 이어서 받을 수 있습니다.
- **예약자 한 줄 메모** — 사전예약 명단의 각 예약자 행 바로 아래 `📝 메모 한 줄`을 탭해 바로 입력합니다(Enter 저장, ✕ 취소 원복). 예약자 추가 폼에도 메모 칸이 있습니다.

### v4에서 달라진 점

- **댓글 접기** — 댓글이 3개 이상이면 **2개만 먼저** 보이고 `💬 댓글 N개 더 보기 ▾` / `댓글 접기 ▴`로 여닫습니다.
  글 카드·공지·고객 통화 기록 모두 같고, 방금 남긴 댓글은 자동으로 펼쳐집니다.
- **1탭 상태 선택** — 고객 줄마다 `미통화 · 부재 · 예약 · 완료` 4칸 버튼이 바로 깔립니다(팝업 없음).
  누르면 그 자리에서 상태가 바뀌고 명단 순서가 튀지 않으며, `완료`를 누르면 줄이 회색 바탕으로 차분해집니다.
  상단 숫자(미통화/부재/예약/완료)·탭 배지·`남은 N`도 함께 갱신됩니다.
- **구분 색상** — `730` 파랑 · `550` 초록 · `3년` 보라. 상단 필터 칩, 고객 줄 배지, 부재중 킵 배지, 고객 시트 배지가 같은 색 규칙을 씁니다.

### v3에서 달라진 점

- **대댓글 접기** — 댓글에 달린 답글은 기본으로 접히고 `답글 N개 보기 ▾` / `답글 접기 ▴`로 여닫습니다.
  방금 남긴 답글은 자동으로 펼쳐집니다.
- **통화 기록 의무 입력** — 고객 시트·상담놓침 글의 댓글/대댓글 입력창 위에 **통화 상태 4칩**이 붙습니다.
  고객 통화 기록은 **상태 + 상담 내용**을 모두 채워야 `등록`이 열리고, 등록하면 고객 상태도 함께 바뀝니다.
- **부재중 킵** — `730·550·3년` 상단 `📵 부재중 킵 (N)`에서 **모든 날짜의 부재 고객 + 직접 킵한 고객**을 한곳에 모아 봅니다.
  한 줄에서 📞 전화, 메모, `＋ 부재 1회`, `예약`·`완료`·`킵 해제`를 바로 처리합니다. 고객 줄의 📌로도 킵할 수 있습니다.
- **시인성** — 고객 줄 왼쪽 4px 상태 바(미통화 레드 · 부재 앰버 · 예약 블루), 상태 칩 테두리, 완료 줄 흐림 처리,
  상단 숫자 스트립의 미통화/부재 색 강조.
- **기간 필터** — `전체 연도 / 2026년 …` ✕ `전체 월 / 11월 …`로 연·월 단위로 추려 보고, 숫자 스트립도 그 기간 기준으로 바뀝니다.
- **정렬** — 날짜별로 항상 `730 → 550 → 3년` 순서, 같은 구분 안에서는 `미통화 → 부재 → 예약 → 완료` 순서.

## 로그인

1. 직원 선택 (김태양 · 김설화 · 이건엽 · 권영한)
2. 매장 공통 비밀번호 4자리 입력 (숫자 키패드)

한 번 입장하면 이 기기에 로그인이 유지되고, 오른쪽 위 이름 → **설정**에서 직원 전환·로그아웃할 수 있습니다.
비밀번호는 소스에 평문으로 두지 않고 해시로만 비교합니다.

## 데이터 보관

- 글·댓글·사진·명단은 이 기기 브라우저의 `localStorage`에 저장됩니다. 서버로 보내지 않습니다.
- **개통장부 연동은 읽기만** 합니다. 장부 앱과 같은 공용 시트를 `/exec?pin=5001&action=list`로 조회할 뿐 장부에 쓰지 않으며,
  받은 목록은 `전화번호 · 개통일 · 담당자`만 남겨 이 기기에 캐시합니다 (`kt_band_ledger_v1`).
- 사진은 첨부할 때 **자동으로 줄여서(JPEG)** 저장합니다.
- 기기를 바꾸기 전에 **설정 → 내보내기**로 JSON 백업을 받아두세요.
- **설정 → 초기화**는 샘플 데이터로 되돌립니다(작성한 내용 삭제).

## 처음 열면

바로 눌러볼 수 있도록 샘플 데이터가 들어 있습니다.
`S26 사전예약 공지`, `상담놓침: 홍길동 010-1234-5678` 같은 예시 글과 730/550/3년 명단·댓글·대댓글이 미리 채워져 있고, 설정에서 초기화하면 다시 채워집니다.
연·월 필터를 확인할 수 있도록 지난 달·지난해 고객 몇 건도 함께 들어 있습니다.

## 파일

```
index.html            앱 전체 (HTML + CSS + JS 한 파일)
manifest.webmanifest  PWA 설정
sw.js                 오프라인 캐시 (문서는 네트워크 우선, 버전 올리면 이전 캐시 삭제)
icons/                홈 화면 아이콘
samples/              샘플 글에 쓰는 예시 사진
thumbs/               밴드 사진 300px 축소본 (목록·댓글용 · 주소 해시 이름)
tools/make_thumbs.py  시드의 새 사진 썸네일 채우기 (없는 것만)
```

## 배포

`main` 브랜치 루트를 GitHub Pages로 올리면 그대로 동작합니다.
캐시는 `sw.js`의 `CACHE` 이름(`kt-band-v8.17`)으로 관리하고, 새 버전은 `skipWaiting()` + `clients.claim()`으로 바로 교체됩니다.
