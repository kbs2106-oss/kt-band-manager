# 칠금점 가망고객 밴드

충주 KT대리점 칠금점 직원용 **가망고객 밴드 웹앱(PWA)** 입니다.
네이버 밴드처럼 공지 · 상담놓침 · 730/550/3년 명단 · 사전예약을 글·사진·댓글·대댓글로 주고받습니다.

- 주소: https://kbs2106-oss.github.io/kt-band-manager/
- 설치: 폰 브라우저에서 주소를 연 뒤 **홈 화면에 추가** (안드로이드 크롬 · 아이폰 사파리)

## 화면

| 탭 | 내용 |
| --- | --- |
| 홈 피드 | 맨 위 **할 일**(미완료 상담놓침·오늘 남은 콜) → 고정 공지(제목 한 줄 + `1/4 개통`) → 글 카드. 카드의 💬 댓글을 누르면 댓글·대댓글·입력창이 열리고, `⋯`에서 완료·공지 고정을 바꿉니다. |
| 730 · 550 · 3년 | 오늘 현황 4칸(미통화·부재·예약·완료, 눌러서 바로 필터) → 구분·상태 필터 + 이름·번호 검색 + 번호 가림 → 날짜별 명단. 고객 줄에서 📞 바로 전화, 상태 칩(눌러서 변경), 담당자 선택, 메모 한 줄 탭 수정(Enter 저장 / ✕ 취소), 💬 통화 기록. |
| ＋ (우측 아래) | 홈 피드에서는 **글쓰기**, 730·550·3년에서는 **명단 추가** 시트가 열립니다. 사진은 카메라·앨범에서 바로 첨부. |

## 로그인

1. 직원 선택 — 김태양 · 김설화 · 이건엽 · 권영한
2. 매장 공통 비밀번호 4자리 입력 (숫자 키패드)

한 번 입장하면 이 기기에 로그인이 유지되고, 오른쪽 위 이름 → **설정**에서 직원 전환·로그아웃할 수 있습니다.
비밀번호는 소스에 평문으로 두지 않고 해시로만 비교합니다.

## 데이터 보관

- 글·댓글·사진·명단은 이 기기 브라우저의 `localStorage`에 저장됩니다. 서버로 보내지 않습니다.
- 사진은 첨부할 때 **자동으로 줄여서(JPEG)** 저장합니다.
- 기기를 바꾸기 전에 **설정 → 내보내기**로 JSON 백업을 받아두세요.
- **설정 → 초기화**는 샘플 데이터로 되돌립니다(작성한 내용 삭제).

## 처음 열면

바로 눌러볼 수 있도록 샘플 데이터가 들어 있습니다.
`S26 사전예약 공지`, `상담놓침: 홍길동 010-1234-5678` 같은 예시 글과 730/550/3년 명단·댓글·대댓글이 미리 채워져 있고, 설정에서 초기화하면 다시 채워집니다.
샘플의 이름·연락처는 모두 가상의 값입니다.

## 파일

```
index.html            앱 전체 (HTML + CSS + JS 한 파일, 빌드 없음)
manifest.webmanifest  PWA 설정
sw.js                 오프라인 캐시 (문서는 네트워크 우선)
icons/                홈 화면 아이콘
samples/              샘플 글에 쓰는 예시 사진
```

## 배포

`main` 브랜치 루트를 GitHub Pages로 올리면 그대로 동작합니다. 빌드 과정은 없습니다.
