# 칠금점 가망고객 밴드

충주 KT대리점 칠금점 직원용 **가망고객 밴드 웹앱(PWA)** 입니다.
네이버 밴드처럼 공지 · 상담놓침 · 730/550/3년 명단 · 사전예약을 글·사진·댓글·대댓글로 주고받습니다.
1단계 댓글은 **고객 한 명(연락처/생년월일 + 부재·예약·완료·개통완료 4칸)**, 대댓글은 **직원 진행 보고**입니다.

- 주소: https://kbs2106-oss.github.io/kt-band-manager/
- 설치: 폰 브라우저에서 주소를 연 뒤 **홈 화면에 추가** (안드로이드 크롬 · 아이폰 사파리)
- 현재 버전: **v8.7**
- 전용 안드로이드 앱: **칠금점 가망고객** APK (v1.0.1 · `apk/kt-band.apk`) (직원 화면 화면 캡처 차단 · 관리자 모드에서만 허용 · 등록 알림)

### v8.7에서 달라진 점

- **고친 뒤에 앱을 껐다 켜지 않아도 화면이 바로 최신으로 바뀝니다** — 예전에는 GitHub Pages 가 `index.html` 을 10분간 캐시해 두고, 새 버전이 설치되어도 다음에 앱을 열 때까지 예전 화면이 떠 있었습니다.
  - 화면(HTML) 요청은 `fetch(req, { cache: 'no-store' })` 로 **HTTP 캐시까지 건너뛰고 항상 네트워크에서** 받습니다. 오프라인일 때만 캐시로 넘어갑니다.
  - 앱을 열 때 · 화면으로 돌아올 때 · 켜 둔 동안 1분마다 `reg.update()` 로 새 버전을 확인하고(`updateViaCache:'none'`), 새 서비스워커가 화면을 넘겨받으면(`controllerchange`) **한 번만 자동 새로고침**합니다(20초 무한루프 가드 · 글 쓰는 중이면 입력칸에서 손을 뗀 뒤).
- **밴드 앱이 개통장부 캐시까지 지우던 문제 수정** — 같은 도메인(`kbs2106-oss.github.io`)을 쓰는 두 앱 중 밴드 쪽 `activate` 가 자기 것 빼고 모든 캐시를 지워, 밴드가 업데이트될 때마다 개통장부의 `kt-ledger-*` 캐시와 SheetJS 캐시가 함께 날아갔습니다. 이제 자기 `kt-band-*` 캐시만 지웁니다.

### v8.5에서 달라진 점

- **이미 개통한 고객은 `🔗 기개통`으로 표시** — `730 · 550 · 3년` 명단에 오늘 올라온 고객이 **원 개통일 이후에 다시 개통(기변·번호이동·신규)한 기록**을 장부에서 찾아, 통화 전에 자동으로 **개통완료**로 바꿉니다.
  배지는 주황색 **`🔗 기개통 (26-10-26 · 김설화)`** — 앞 날짜는 **장부의 마지막 재개통일**, 괄호는 그 건의 담당자입니다. 고객 시트 💬 통화 기록에도
  `🔗 기개통 — 2026-10-26에 재개통 (담당 김설화) · 원 개통 2024-11-26 이후라 자동 개통완료` 한 줄이 남습니다.
  - 원 개통일은 명단 날짜에서 약정기간을 역산합니다(`730` 729일 전 · `550` 549일 전 · `3년` 1094일 전).
  - **원 개통 건 자신은 잡히지 않도록** 그 15일 뒤부터만 봅니다(`730` 명단 −715일 · `550` −535일 · `3년` −1080일). 2년 전 본인 개통 기록으로 잘못 개통완료가 되지 않습니다.
  - 같은 고객이 **재개통한 날 기준 2년 뒤** 다시 명단에 오르면, 그 재개통 건은 자기 자신이라 제외되어 **미통화**로 정상 노출됩니다.
  - 명단 날짜 이후 새 개통이 있으면 기존 **`🔗 장부 자동개통완료`**가 우선입니다(지금 새로 개통한 건).
  - 라이브 장부 **10,092건**(2023-05~2026-11) × 최근 3개월 명단 1,942명 대조: **532명 개통완료**(새 개통 66 · **기개통 466**), 오늘(11-25) 명단 11명 중 **5명**이 기개통으로 바뀌었습니다. 원 개통 건 오매칭 0건.

### v8.4에서 달라진 점

- **홈 피드는 `매장 공지` · `상담` · `사전예약`만** — 필터도 **`전체 | 매장 공지 | 상담 | 사전예약`** 네 칸으로 정리했습니다.
  매일 올라오던 **`730·550·3년` 표 글은 홈 피드에서 감춥니다**(표는 `730·550·3년` 탭에 그대로 있습니다). 상단 `📌 고정 공지`는 **중요공지 2건**만 +
  `📢 전체 공지 25건 ›`로 전체 목록을 열람합니다. `전체`는 최신 6건만 보이고 `글 N건 더 보기`로 펼칩니다.
  공지 분류는 **`사전예약` 글만 사전예약**, 나머지 공지(월별 상담건 · 550/730 · 전단 활동 공유 등)는 **상담**입니다. 글쓰기(`＋`)도 **매장 공지 / 상담 / 사전예약** 세 가지.
- **명단 생년월일 크게** — 고객 줄 이름 옆에 **`1959-04-10`**(15px 굵은 검정) + **`만 67세`**(작은 회색)로 선명하게 표시합니다(🎂 이모지 없음). 미기재는 `생일 없음`.
- **명단 상단 정리** — `기간(전체 연도·전체 월)` 아래 **구분 1줄**(`전체 730 550 3년`) · **상태 1줄**(`미통화 부재 예약 완료 개통완료`) · **검색 1줄(풀폭)**.
  번호 가림 `🔒` 버튼은 뺐습니다. 명단 탭을 열면 **기간이 당월(예: 2026년 11월)로 자동 선택**됩니다.
- **상태 칸을 누르면 그 자리에 목록** — 작은 창 대신 명단 아래 영역에 바로 모입니다. `부재`/`부재중 킵`은 부재·킵 고객을, `예약`/`⏰ 예약 알람`은 **예약 날짜·시간 순**(메모 포함)으로 보여주고,
  같은 칸을 한 번 더 누르거나 `전체 명단 ›`로 일별 명단으로 돌아옵니다.
- **예약 메모** — 예약 날짜·시간 시트에 **예약 메모** 칸이 생겼습니다. 저장하면 고객 카드 메모와 `⏰ 예약 알람` 카드에 함께 보입니다.
- **부재는 최근 3개월(90일)까지** — `부재`·`부재중 킵` 카운트와 목록은 기간 설정과 상관없이 **오늘 기준 90일 이내 부재 고객 + 상담 공지의 부재 댓글**을 모두 모아 보여줍니다(미완료 건).
- **예약 취소 정리** — `예약`에서 `미통화`·`부재`·`완료`·`개통완료`로 바꾸면 **예약 날짜·시간이 함께 지워져** 예약 알람·예약 목록·예약 카운트에서 즉시 빠집니다.

### v8.3에서 달라진 점

- **명단에 생년월일** — `730·550·3년` 고객 줄 이름 아래에 **`🎂 1959-04-10 만 67`** 칩이 붙습니다. 고객 시트에는 `생년월일` 줄이 따로 있고,
  검색창에 **생년월일(`1959` 또는 `1959-04-10`)로도 찾을 수 있습니다**. 생년월일은 개통장부·정산 자료에서 **전화번호(없으면 이름+번호)** 로 맞춰 채웠고,
  원본이 비어 있는 건(최근 3개월 197건 · 외국인·중고MNP 등)은 억지로 만들지 않고 `🎂 없음`·시트 `기록 없음`으로 둡니다.
- **예약 버튼 → 날짜·시간 선택** — 명단 카드·고객 시트·홈 피드 1단계 댓글에서 **`예약`**을 누르면 바로 날짜·시간 시트가 열립니다.
  `오늘 / 내일 / 모레 / 3일 뒤 / 1주 뒤` 빠른 선택 + 날짜(`YYYY-MM-DD`) + 시간(선택)을 고르면 **`⏰ 예약 11/27(오후 2:00)`** 배지가 그 자리에 붙습니다.
  이미 예약인 건에서 다시 누르면 **날짜 수정**과 **예약 취소(미통화로)**를 고를 수 있습니다.
- **⏰ 예약 알람 카드** — 오늘 날짜이거나 기한이 지난 예약이 있으면 홈 피드·명단 맨 위에 **`⏰ 예약 알람 N`** 카드가 따로 뜹니다.
  줄을 누르면 그 고객 시트(또는 그 댓글이 있는 글)가 열려 바로 통화할 수 있고, 4건이 넘으면 `나머지 N건 더 보기`로 펼칩니다.
- **폰 알림** — 예약을 저장하면 `KTBandBridge.notify('⏰ 예약 알람', '고객 · 11/27(오후 2:00)')`로 한 번 알리고,
  앱을 열 때 오늘·지난 예약 건을 **하루 한 번**(같은 예약은 다시 울리지 않음) 알립니다. 알람 예약 훅(`KTBandBridge.scheduleAlarm`)이 있는 앱이면 함께 걸어 둡니다.

### v8.1에서 달라진 점

- **관리자 모드에서만 화면 캡처 허용** — 설정(오른쪽 위 이름) → **🔐 관리자 모드** → 관리자 PIN 4자리를 넣으면
  이 화면을 **캡처·녹화**할 수 있습니다. 켜져 있는 동안 상단 탭 아래에 **노란 줄 `🔓 관리자 모드 · 화면 캡처 허용 중`**이 뜨고,
  **10분이 지나면 자동으로 다시 잠깁니다**(설정 → 관리자 모드 → `지금 잠그기`로 바로 잠글 수도 있습니다).
  로그아웃·직원 전환·초기화 때도 즉시 잠깁니다. 직원 화면은 **항상** 캡처가 막힙니다.
- **전용 앱 연결** — 위 상태가 바뀔 때마다 `window.KTBandBridge.setCaptureAllowed(true|false)`를 호출합니다.
  전용 APK가 그 값을 받아 `FLAG_SECURE`를 켜고 끄며, 앱이 뒤로 가면(홈으로 나가면) 관리자 모드여도 **최근 앱 미리보기를 다시 가립니다**.
  일반 브라우저(PWA)에는 이 다리가 없어 아무 일도 일어나지 않습니다(브라우저 자체 캡처는 막을 수 없습니다).
- 알림 훅(`KTBandBridge.notify`)은 v8 그대로 — 전용 앱이 붙으면 완료·개통완료·메모·댓글 등록이 안드로이드 알림으로 뜹니다.

### v8에서 달라진 점

- **실제 밴드 데이터가 기본 시드** — 테스트용 샘플(`홍길동`, `김민준`, `S26 사전예약` 등)은 완전히 빠졌습니다.
  기본 시드는 실제 밴드 `칠금점 가망고객` 글 **67건 · 댓글 1,041건 · 답글 46건**과 최근 3개월(**2026-09-01~11-25**) 고객 **1,942건**이고,
  과거일은 전부 `완료`, 오늘(11-25)은 `730` **11건만 `미통화`** 입니다. 시드는 `index.html` 안에 들어 있어 인터넷이 없어도 첫 실행부터 실제 명단이 뜹니다.
- **v1~v7 저장본은 1회 자동 교체** — 이 기기에 남아 있던 옛 테스트 데이터(`seedVersion < 8`)는 앱을 열 때 새 실데이터로 **한 번 깨끗이 교체**됩니다.
- **과거 전체 10,066건 조회** — `archive.json`(10,066건 · 2024-11-10~2026-11-25, 약 3.4MB)을 앱이 백그라운드에서 한 번 받아 **IndexedDB**에 넣어 두고,
  `730·550·3년` 탭에서 **2026-08 이전 연/월을 고르거나 검색할 때** 전체 10,066건에서 찾습니다. `localStorage`(5MB 한도)에는 최근 3개월만 저장하므로 용량 걱정이 없고,
  과거 고객의 상태·메모를 고치면 **그 고객 한 건만** 이 기기 저장본으로 복사돼 수정이 남습니다. `archive.json`은 서비스워커가 미리 받지도, 캐시에 쌓지도 않습니다.
- **상태 버튼 4칸 확정 — `부재 · 예약 · 완료 · 개통완료`** — 고객 줄·고객 시트·홈 피드 1단계 댓글의 4칸에서 **`미통화` 버튼을 뺐습니다**.
  아무것도 선택하지 않은 기본값이 **미통화**이고, **같은 칸을 한 번 더 누르면 선택이 풀려 미통화**로 돌아갑니다.
  상단 숫자 스트립(미통화·부재·예약·완료·개통완료)과 필터 칩에서는 그대로 `미통화` 건수를 보고 걸러낼 수 있습니다.
- **`완료`와 `개통완료` 구분** — `완료`는 **통화 완료**, `개통완료`는 **실제 개통까지 끝난 건**입니다.
  개통장부 자동 연동으로 매칭된 고객은 `개통완료`로 자동 반영되고(`🔗 장부 자동개통완료` 배지), 개통완료는 4칸에서 진한 초록으로 표시됩니다.
- **알림 훅** — 상태 변경(완료·개통완료 등)·메모 저장·댓글/답글 등록 때 `window.KTBandBridge.notify(제목, 내용)`를 호출합니다.
  전용 APK가 붙으면 Android 시스템 알림으로 바로 뜨고, 지금 웹에서는 조용히 넘어갑니다.
- **명단은 6일씩** — 날짜 카드가 713일치라 한 번에 다 그리지 않고 최근 6일만 보여주며 `이전 날짜 더 보기`로 10일씩 늘립니다. 기간(연/월)·검색은 40일까지 한 번에 보여줍니다.

### v7에서 달라진 점

- **개통장부 자동 연동** — 개통장부(`kt-store-manager`)가 쓰는 공용 구글 시트(Apps Script `/exec`, 매장 PIN `5001`)를 **읽기만** 해서
  **전화번호 뒤 8자리가 같고 개통일이 그 가망고객 날짜(당일 포함) 이후**인 건이 있으면 고객 상태를 자동으로 **개통완료**로 바꿉니다.
  `[정산이관]`으로 넘어온 과거 이관 건도 개통일이 그 날짜 이후면 똑같이 매칭합니다.
  바뀐 고객 줄·고객 시트에는 **`🔗 장부 자동개통완료 (11-24 · 김설화)`** 초록 배지가 붙고, 통화 기록에 `장부 연동` 시스템 댓글이 남습니다.
  사전예약 명단의 예약자도 같은 기준으로 `개통 체크`가 자동으로 켜지고 `🔗 장부 자동개통완료` 줄이 표시됩니다.
  `부재중 킵`에 있던 고객은 개통완료가 되면 킵에서 자동으로 빠집니다.
- **장부 트래픽 최소화** — 앱을 열면 이 기기에 저장해 둔 장부 캐시로 **먼저** 대조하고(네트워크 없이 즉시),
  자동 확인은 **30분에 한 번** `ping`(작은 응답)으로 건수만 봅니다. 건수가 달라졌을 때만 목록(약 5 MB)을 새로 받고,
  받은 목록은 `전화번호 · 개통일 · 담당자` 3칸만 남겨 캐시합니다. 수동 `지금 확인`은 60초 쿨다운을 둡니다.
- **장부 연동 상태 표시** — 명단 맨 위 **🔄 장부 개통 연동** 줄에 `장부 10,092건 · 3분 전 확인 · 방금 2명 자동 반영`처럼 상태가 보이고,
  오른쪽 **지금 확인** 버튼(설정 시트에도 같은 항목)으로 언제든 즉시 대조할 수 있습니다.
- **고정 공지는 접히지 않음** — `전체` 필터나 `모두 접기`를 눌러도 **피드 글의 댓글만** 접히고, 상단 **고정 공지**는 그 옆의
  자체 `접기` 버튼을 눌렀을 때만 접힙니다.
- **메모는 저장을 눌렀을 때만** — 명단·사전예약·부재중 킵의 인라인 메모를 고치다가 `저장`(또는 `Enter`)을 누르지 않고
  다른 고객·다른 버튼·다른 시트·다른 탭을 누르거나 포커스를 잃으면, 쓰던 내용은 버려지고 **원래 저장돼 있던 메모가 그대로** 돌아옵니다.
- **상태를 직접 바꾸면 그 선택이 우선** — 장부에 개통 기록이 있어도 직원이 `미통화·부재·예약`으로 바꾸면 그대로 두고,
  배지만 `🔗 장부 개통 (11-24 · 김설화)`로 바뀝니다(다시 `개통완료`로 두면 자동 표시가 살아납니다).

### v6에서 달라진 점

- **홈 피드 기본 접힘** — 글 카드는 `글 종류 배지 + 제목 + 본문 + [💬 댓글 N개 보기] + [처리완료]`만 보여줍니다.
  댓글이 있는 글만 `💬 댓글 N개 보기 ▾`로 열리고, 다시 누르면 `💬 댓글 접기 ▴`로 접힙니다. 댓글·대댓글·입력창이 피드에 미리 깔리지 않아 피드가 짧고 차분해졌습니다.
- **모두 접기 / 모두 펼치기** — 필터 줄 맨 왼쪽 버튼 한 번으로 **모든 글의 댓글·대댓글**을 한꺼번에 접습니다(`전체` 필터를 눌러도 같이 접힘). *(v7부터 고정 공지는 접히지 않습니다)*
- **글 종류가 0.5초에 보임** — 카드 왼쪽 **4px 컬러 바** + 오른쪽 위 **배지**로 구분합니다.
  `상담놓침` 빨강(`#EF4444`), `사전예약` 보라(`#7C3AED`), `매장 공지` 파랑(`#0B57D0`), `메모` 회색. 제목은 17px 굵게, 본문은 15px로 키워 위에서 아래로 훑기만 해도 무슨 글인지 보입니다.
- **전체 시인성** — 배경 `#F4F6F9` ↔ 흰 카드 `#FFFFFF` + 선명한 보더(`#E3E8EF`)와 옅은 그림자.
  고객 이름 17px·굵게, 전화번호 15.5px·굵게, `남은 N`·`미통화 N`·상단 숫자는 더 크고 진하게. 흐리던 보조 글자는 `#475569` 이상으로 올려 읽기 편하게 정리했습니다.
- **상태 이름 `완료` → `개통완료`** — 명단 4칸, 상단 숫자, 필터 칩, 댓글 4칸, 부재중 킵, 고객 시트, 사전예약까지 모두 `개통완료`로 통일했습니다.
  글 자체를 마감하는 버튼은 `처리완료`입니다. (저장된 상태 값은 그대로라 기존 데이터가 깨지지 않습니다.)

### v5에서 달라진 점

- **댓글이 곧 고객 카드** — 글(예: `11월 상담건`, `상담놓침`)의 **1단계 댓글마다** `미통화 · 부재 · 예약 · 완료` 4칸 버튼이 붙습니다.
  댓글에 `01037795774/970114`처럼 고객 정보를 남기고 버튼 한 번으로 상태를 바꾸면, `완료`는 그 댓글 블록이 차분한 회색(`#F1F3F5`)으로 마감됩니다.
  **대댓글(답글)에는 상태 버튼이 없습니다** — 직원 진행 내용·사진만 남기고 `답글 N개 보기 ▾`로 접었다 펴며, 댓글 입력창도 답글 모드로 바꾸면 상태 칩이 사라집니다.
- **사전예약 공지 작성** — `＋ 글쓰기`의 `사전예약 공지`로 올리면 **상단 고정 공지 + 사전예약 탭**에 바로 뜨고(고정은 기본 체크, 해제 가능),
  글 안에서 `＋ 예약자 추가`와 `개통 체크(N/M 개통)`를 바로 관리합니다. 등록 직후 그 글이 열려 예약자를 이어서 받을 수 있습니다.
- **예약자 한 줄 메모** — 사전예약 명단의 각 예약자 행 바로 아래 `📝 메모 한 줄`을 탭해 바로 입력합니다(Enter 저장, ✕ 취소 원복). 예약자 추가 폼에도 메모 칸이 있습니다.

### v4에서 달라진 점

- **댓글 접기** — 댓글이 3개 이상이면 **2개만 먼저** 보이고 `💬 댓글 N개 더 보기 ▾` / `댓글 접기 ▴`로 여닫습니다.
  글 카드·공지·고객 통화 기록 모두 같고, 방금 남긴 댓글은 자동으로 펼쳐집니다.
- **1탭 상태 선택** — 고객 줄마다 `미통화 · 부재 · 예약 · 완료` 4칸 버튼이 바로 깔립니다(팝업 없음).
  누르면 그 자리에서 상태가 바뀌고 명단 순서가 튀지 않으며, `완료`를 누르면 줄이 회색 바탕으로 차분해집니다.
  상단 숫자(미통화/부재/예약/완료)·탭 배지·`남은 N`도 함께 갱신됩니다.
- **구분 색상** — `730` 파랑 · `550` 초록 · `3년` 보라. 상단 필터 칩, 고객 줄 배지, 부재중 킵 배지, 고객 시트 배지가 같은 색 규칙을 씁니다.

### v3에서 달라진 점

- **대댓글 접기** — 댓글에 달린 답글은 기본으로 접히고 `답글 N개 보기 ▾` / `답글 접기 ▴`로 여닫습니다.
  방금 남긴 답글은 자동으로 펼쳐집니다.
- **통화 기록 의무 입력** — 고객 시트·상담놓침 글의 댓글/대댓글 입력창 위에 **통화 상태 4칩**이 붙습니다.
  고객 통화 기록은 **상태 + 상담 내용**을 모두 채워야 `등록`이 열리고, 등록하면 고객 상태도 함께 바뀝니다.
- **부재중 킵** — `730·550·3년` 상단 `📵 부재중 킵 (N)`에서 **모든 날짜의 부재 고객 + 직접 킵한 고객**을 한곳에 모아 봅니다.
  한 줄에서 📞 전화, 메모, `＋ 부재 1회`, `예약`·`완료`·`킵 해제`를 바로 처리합니다. 고객 줄의 📌로도 킵할 수 있습니다.
- **시인성** — 고객 줄 왼쪽 4px 상태 바(미통화 레드 · 부재 앰버 · 예약 블루), 상태 칩 테두리, 완료 줄 흐림 처리,
  상단 숫자 스트립의 미통화/부재 색 강조.
- **기간 필터** — `전체 연도 / 2026년 …` ✕ `전체 월 / 11월 …`로 연·월 단위로 추려 보고, 숫자 스트립도 그 기간 기준으로 바뀝니다.
- **정렬** — 날짜별로 항상 `730 → 550 → 3년` 순서, 같은 구분 안에서는 `미통화 → 부재 → 예약 → 완료` 순서.

## 로그인

1. 직원 선택 (김태양 · 김설화 · 이건엽 · 권영한)
2. 매장 공통 비밀번호 4자리 입력 (숫자 키패드)

비밀번호는 소스에 평문으로 두지 않고 해시로만 비교합니다.

## 데이터 보관

- 글·댓글·사진·명단은 이 기기 브라우저의 `localStorage`에 저장됩니다. 서버로 보내지 않습니다.
- **개통장부 연동은 읽기만** 합니다. 장부 앱과 같은 공용 시트를 `/exec?pin=5001&action=list`로 조회할 뿐 장부에 쓰지 않으며,
  받은 목록은 `전화번호 · 개통일 · 담당자`만 남겨 이 기기에 캐시합니다 (`kt_band_ledger_v1`).

- 기기를 바꾸기 전에 **설정 → 내보내기**로 JSON 백업을 받아두세요.
- **설정 → 초기화**는 샘플 데이터로 되돌립니다(작성한 내용 삭제).

## 배포

`main` 브랜치 루트를 GitHub Pages로 올리면 그대로 동작합니다.
캐시는 `sw.js`의 `CACHE` 이름(`kt-band-v8.1`)으로 관리하고, 새 버전은 `skipWaiting()` + `clients.claim()`으로 바로 교체됩니다.
