# 밴드앱 실시간 공유 서버 (v8.9)

`칠금점 가망고객` 앱(kt-band-manager)이 **전 직원 폰에서 같은 명단·상태를 보게** 해 주는 서버 코드입니다.
개통장부가 이미 쓰고 있는 **같은 스프레드시트 + 같은 Apps Script** 에 그대로 붙습니다.

## 어디에 붙이나

이 폴더의 `Code.gs` 는 `kt-store-manager/apps-script/Code.gs`(개통장부 공용 시트 코드)와
**완전히 같은 파일**입니다. 새 파일을 만들 필요 없이, 이미 쓰고 있는 Apps Script 편집기에
**이 파일 전체를 붙여넣고 새 버전으로 배포**하면 끝입니다.

1. 스프레드시트(`1DjKKQT9K2ryDKjRL88B31pMhdqgqlzEX39uDbG8F4E4`) → **확장 프로그램 → Apps Script**
2. 왼쪽 `Code.gs` 를 열고 **기존 내용을 모두 지운 뒤** 이 파일 내용을 통째로 붙여넣기
3. **저장**(Ctrl+S)
4. **배포 → 배포 관리 → (지금 쓰는 배포) 오른쪽 연필 ✏️ → 버전: 새 버전 → 배포**
   - 주소(`https://script.google.com/macros/s/…/exec`)는 그대로 유지됩니다.
   - 새 배포를 만들면 주소가 바뀌므로 꼭 **기존 배포의 '버전'만 올려** 주세요.
5. 시트에 숨김 탭 **`_밴드공유`** 가 자동으로 생깁니다(직접 고치지 마세요).

> ⚠️ **지금 개통장부가 쓰고 있는 그 스크립트**에서 작업하세요. **새 프로젝트를 만들면 주소가 바뀌어**
> 개통장부·밴드 앱 둘 다 주소를 다시 넣어야 합니다. `배포 → 배포 관리 → 지금 쓰는 배포의 ✏️ → 버전만 새 버전` 으로 올리면 주소가 그대로입니다.

배포 전에는 앱이 `band_get` 대신 `지원하지 않는 요청입니다` 를 받아 **조용히 혼자 쓰는 모드**로
동작하고, 배포가 끝나면 30초 안에 앱이 스스로 알아채고 **실시간 공유를 켭니다**(앱 업데이트 불필요).

## 무엇을 하나

| 요청 | 하는 일 |
|---|---|
| `GET ?pin=5001&action=band_get&since=…` | `since` 이후 바뀐 항목만 JSON 으로 (JSONP `callback=` 도 지원) |
| `POST {pin, action:'band_push', staff, items:[…]}` | 직원이 바꾼 **칸만** 받아 항목·칸 단위로 합치기 |

- 숨김 탭 `_밴드공유` 한 줄 = 고객 1명(`c:<id>`) 또는 글 1건(`p:<id>`)
- 고객 A를 완료 + 고객 B를 부재처럼 **서로 다른 항목**은 물론,
  같은 고객의 **서로 다른 칸**(상태 vs 메모)도 서로 덮어쓰지 않습니다.
- 댓글·답글은 id 로 합집합(같은 댓글은 더 새것만) — 동시에 달아도 사라지지 않습니다.
- `LockService` 로 동시 저장을 한 줄로 세우고, 한 칸 50,000자 제한을 넘지 않게
  본문 12,000자·댓글 2,000자로 자르고 오래된 댓글은 60건까지만 보관합니다.
- 사진은 **주소(https)만** 공유합니다. 폰에서 찍어 붙인 사진(기기 안에만 있는 큰 이미지)은
  글이나 댓글 내용만 공유되고 사진은 그 기기에만 남습니다.
